V+# Personal Expense Tracker

A simple command-line application to track personal expenses, categorize them, and visualize spending patterns using graphs.

---

## Features
- **Add Expenses**: Add expenses with details like date, category, and amount.
- **View Expenses**: View all expenses in a tabular format.
- **Save and Load Data**: Save expenses to a CSV file and load them later.
- **Data Visualization**: Generate pie charts and bar graphs to visualize spending patterns.

---

## Requirements
- Python 3.x
- Libraries: `pandas`, `matplotlib`

---
